# Prompt Transformation Lab

A structured prompt-engineering project that transforms weak, vague, or incomplete prompts into professional prompts with clear context, requirements, constraints, output formats and success criteria.

## Project Goal

The goal of this project is to demonstrate how prompt quality can be improved through:

* Intent detection
* Context analysis
* Requirement gathering
* Constraint definition
* Audience identification
* Structured output design
* Prompt evaluation

## Example

### Weak Prompt

```text
Explain machine learning.
```

### Improved Prompt

```text
You are an experienced machine learning educator.

Explain machine learning to a college student with no previous AI experience.

Use simple language, avoid advanced mathematics, include three real-world examples and organize the response using clear Markdown headings.
```
